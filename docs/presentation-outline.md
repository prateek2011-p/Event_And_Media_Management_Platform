# Presentation Outline

## Slide 1: Problem

Club event media is scattered across drives, phones, and personal storage, making it difficult to organize, search, share, and reuse.

## Slide 2: Solution

Creative Ink Guild Media Hub centralizes event albums, access control, media upload, AI tagging, social interaction, and personalized photo discovery.

## Slide 3: User Roles

Admin manages events, photographers upload albums, club members access private media, and viewers browse public media.

## Slide 4: Core Features

Event management, drag-and-drop bulk upload, role-based privacy, social actions, smart tags, advanced search, notifications, and watermark downloads.

## Slide 5: AI and Personalization

AI-style tag generation, generated captions, face-profile matching, and a path for production ML services.

## Slide 6: Cloud and Scalability

Local demo storage is abstracted behind a cloud status endpoint. Production can move media objects to AWS S3 with CDN delivery and async processing.

## Slide 7: Bonus Features

PWA offline cache, QR-based sharing, analytics dashboard, collaborative album schema, infinite gallery loading, duplicate-ready metadata.

## Slide 8: Architecture

PWA frontend, Node API, role policy layer, persistence store, cloud adapter, AI service adapter, and notification workflow.

## Slide 9: Demo Flow

Switch roles, create event, upload media, search by tags, like/comment, view notifications, find face matches, download watermarked media.

## Slide 10: Future Work

JWT auth, S3 multipart upload, WebSocket notifications, moderation model, real face recognition, Docker, CI/CD, and deployed demo.
